🔄 Come usare Remap

  1. Posiziona il robot sul nodo Start (di default nodo 0)
  2. Premi ⊕ Calibra — il punto blu appare sul nodo
  3. Assicurati che il tratto in avanti sia rettilineo per ~5 nodi (~60 cm)
  4. Premi 🔄 Remap — il robot parte automaticamente in avanti
  5. Il robot si ferma dopo ~60 cm (failsafe timeout 1.5×)
  6. La mappa viene ricalibrata: traslazione + rotazione + scala
  7. ⚠ Timeout: odometria lenta o robot fermo — riposiziona e riprova
