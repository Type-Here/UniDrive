🔄 Come usare Remap

  1. Posiziona il robot sul nodo Start (di default nodo 31)
  2. Premi ⊕ Calibra — il punto blu appare sul nodo
  3. Assicurati che il tratto in avanti sia rettilineo per 1 nodo (~45 cm)
  4. Premi 🔄 Remap — il robot parte automaticamente in avanti
  5. Il robot si ferma dopo ~45 cm (failsafe timeout 1.5×)
  6. La mappa viene ricalibrata: traslazione + rotazione + scala
  7. ⚠ Timeout: odometria lenta o robot fermo — riposiziona e riprova
  8. ⚡ Quick remap (alternativa, senza guida): posiziona il robot sul nodo Start rivolto verso il nodo successivo e premi — calcola rotazione + traslazione dalla posa odometrica attuale (rotazione dallo yaw fuso col giroscopio). Più robusto agli errori di posizione/baseline; richiede però un buon allineamento angolare manuale
